# 30 / 60 / 90 Day Platform Roadmap

## First 30 days
- map deploy paths, AWS accounts, clusters, service dependencies, and incidents
- baseline SLOs for ordering/payment-critical services
- standardize container and Helm conventions
- document rollback and incident ownership
- identify largest cloud-cost drivers

## By 60 days
- reusable EKS/Spring golden path
- CI contract gates
- automated image scanning
- OpenTelemetry service baseline
- canary promotion checks
- workload identity and secrets baseline
- SLO burn-rate alerts

## By 90 days
- progressive delivery automation
- multi-environment promotion workflow
- disaster-recovery exercise
- service/platform scorecards
- cost-per-service visibility
- peak-window capacity forecasts
- safe schema migration automation
